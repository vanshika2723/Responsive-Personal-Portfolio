## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vanshika2723/vanshika2723.github.io.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, use the **Live Server** extension in VS Code.

---

## 🌐 Deployment

This portfolio can be deployed using **GitHub Pages**.

Basic Git commands:

```bash
git add .
git commit -m "Update portfolio website"
git push origin main
```

After pushing the changes, GitHub Pages will update the live website.
